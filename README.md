# TeamSetu — HR SaaS Platform

HR software your whole team will actually love. Hiring, onboarding, time off, and performance in one simple platform.

Built with Next.js 14 (App Router).

## Pages

- `/` — Landing page (hero, features, testimonials, FAQ)
- `/features` — Detailed feature breakdown
- `/pricing` — Plans with monthly/annual toggle
- `/signup` — Trial signup → demo dashboard
- `/login` — Login → demo dashboard
- `/dashboard` — Interactive demo: overview KPIs, employee directory, time-off approvals

## Run locally

```bash
npm install
npm run dev
```
